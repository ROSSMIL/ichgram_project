# ICHGRAM

This repository contains a full-stack social media application inspired by Instagram, built using React for the frontend and Node.js for the backend.

📋 Features & Functionality

- **Authentication:** Secure registration and login system.
- **Home Feed:** View posts from the community on the home screen.
- **Explore:** Discover and browse content from all users.
- **User Interaction:** Follow other users and like their posts.
- **Content Management:** Create and share new posts via the "Create" functionality.
- **User Search:** Find and navigate to other user profiles.
- **Profile Page:** Dedicated view for personal content and account information.
- **In Development:** Messaging, Notifications, Password recovery features are currently under active development.

---

## 🚀 How to Run

Follow these steps to launch the application locally:

### 1. Backend

Navigate to the backend directory and start the server:

```bash
cd backend
npm install
npm start
```

### 2. Frontend

Navigate to the frontend directory and start the development server:

```bash
cd frontend
npm install
npm run dev
```
